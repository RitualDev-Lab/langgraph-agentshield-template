# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this template or in AgentShield, please report it via encrypted email to:

**security@ritualdev.in**

- Guaranteed initial triage SLA: **< 2 hours**
- Guaranteed hotfix SLA: **< 24 hours**
- Full disclosure policies and CVE listings: [https://ritualdev.in/advisories](https://ritualdev.in/advisories)
